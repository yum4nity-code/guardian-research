# Maman 70 — Santorin

Projet familial pour organiser les 70 ans de Maman à Santorin.

## Décision actuelle
- Destination : **Santorin**
- Dates : **vendredi 16 → lundi 19 octobre 2026**
- Voyageurs : 3 adultes
- Chambres : **3 chambres séparées**
- Petit-déjeuner : souhaité inclus si possible
- Base recherchée : **Fira / Firostefani / Karterados**, priorité au rapport emplacement/prix
- Voiture de location : **non prévue**
- EasyJet : à éviter

## Départs
- Gwen : **Bâle (BSL)**
- Mag : **Nice (NCE)**
- Maman : **Toulouse (TLS)**

## Objectif logistique
Faire converger les arrivées le vendredi en fin de journée, idéalement entre **18h00 et 21h30**, puis un transfert unique ou coordonné vers l’hôtel.

## Budget
Le budget initial de 1 950 € pour trois est désormais considéré trop bas avec 3 chambres séparées. Cible réaliste actuelle : **environ 2 500 à 3 000 €**, à resserrer après réservation des vols et de l’hôtel.

# Handoff directory

This directory preserves Guardian continuity and agent-to-agent transfer material.

## Current handoff

Current detailed R4/R5 state:

`2026/09/11/GUARDIAN_R4_R5_CURRENT_HANDOFF_2026_09_11.md`

Always enter through the top-level:

`CURRENT_PROJECT_HANDOFF.md`

That file points to the current dated handoff.

## Directory conventions

- `YYYY/MM/DD/` — dated project continuity snapshots.
- `archive/` — superseded summary documents retained for provenance.
- `chatgpt_to_codex/` — historical ChatGPT → Codex exchanges.
- `codex_to_chatgpt/` — historical Codex → ChatGPT exchanges.
- `guardian_next_ai/` — earlier restart/takeover packages.

The historical subtrees are not current instructions unless explicitly referenced by the current canonical handoff.

## Preservation rule

Do not delete historical handoffs just because they are stale. They may document:
- preregistration intent;
- version lineage;
- infrastructure failure classification;
- rejected scientific families;
- production/compliance decisions.

Cleanliness should come from a clear current index, not from erasing provenance.

# Mini-app familiale

Mini-app interactive créée pour aider Mag à choisir la destination et les paramètres du séjour.

## Résultat du questionnaire
- Dates : **16 → 19 octobre 2026**
- Option affichée : **Santorin**
- Classement :
  1. Santorin — 32 pts
  2. Malte — 28 pts
  3. Athènes — 24 pts

## Déploiement Vercel
Projet : `weekend-70-maman`
URL production :
https://weekend-70-maman.vercel.app

## Fonctionnalités ajoutées
- questionnaire interactif
- choix des dates
- classement des destinations
- budgets approximatifs
- cartes destinations cliquables
- liens de réservation calibrés sur les dates
- liens Google Maps dans le récapitulatif
- bouton `Bro update` qui prépare un mail vers `gwennaelsalinas@gmail.com` avec le résultat
- consignes iPhone pour ajouter la PWA à l’écran d’accueil

## Note
L’app est un outil de comparaison / présentation. Les réservations finales doivent toujours être vérifiées sur les sites compagnies / hôtels car les tarifs changent.
